Online_ParterGame Documentation

1) Project overview
This repository contains an online behavioral experiment task.
Main task file: Parter_RewardGame.html

2) Task phases
- Learning phase: choose one cue from 2-3 abstract cues, with outcome feedback.
- Transfer phase: choose between learned cue pairs, no outcome feedback.
- Explicit rating phase: rate each cue from 0 to 100, no outcome feedback.

3) How to run
Open Parter_RewardGame.html directly in a modern browser.
